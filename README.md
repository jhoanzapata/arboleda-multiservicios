# ARBOLEDA MULTISERVICIOS

> Plataforma Web Corporativa & Motor de Conversión Comercial de Alto Rendimiento para Servicios Integrales de **Climatización (HVAC)**, **Construcción & Reformas** y **Herrería & Estructuras Metálicas** en la Provincia de Alicante, España.

---

## 🌟 Características Principales

- **Arquitectura Frontend Moderna:** Desarrollada con **React 19**, **TypeScript**, **Vite** y **Tailwind CSS v4**.
- **Soporte Multilingüe Completo (7 Idiomas):**
  - 🇪🇸 **Español (`ES`):** Mercado nacional y autonómico.
  - 🔴🟡 **Valencià (`VA`):** Lengua cooficial para comunidades de vecinos y administradores de fincas.
  - 🇬🇧 **English (`EN`):** Residentes británicos y mercado internacional.
  - 🇩🇪 **Deutsch (`DE`):** Comunidad de residentes alemanes y suizos.
  - 🇫🇷 **Français (`FR`):** Clientes de Francia, Bélgica y Suiza.
  - 🇳🇱 **Nederlands (`NL`):** Residentes de Países Bajos y Flandes.
  - 🇷🇺 **Русский (`RU`):** Propietarios de chalets y villas de alto standing en la Costa Blanca.
- **Catálogo de 9 Especialidades con Desglose Técnico:** Inclusiones detalladas, ventajas de eficiencia energética y botones de WhatsApp directo.
- **Simulador Interactivo de Presupuestos:** Generación de solicitudes pre-estructuradas en 3 clics para WhatsApp.
- **Galería de Vídeos Reales (`VideoGallery`):** Reproductor interactivo de instalaciones de automatismos y motores.
- **Galería de Proyectos con Lightbox (`ProjectGallery`):** Filtros por especialidad y visualización en alta definición.
- **Metodología en 4 Pasos (`ProcessSection`):** Solicitud → Visita Gratuita → Ejecución → Entrega con Garantía Escrita.
- **Cumplimiento Legal & Normativa Española/UE:**
  - Aviso Legal conforme a **LSSI-CE Art. 10**.
  - Política de Privacidad conforme al **RGPD UE 2016/679**.
  - Banner y Política de Cookies conforme a la **AEPD / UE**.
  - Términos y Condiciones de Servicio.
- **SEO & Datos Estructurados:** Schema.org `LocalBusiness` JSON-LD, `sitemap.xml` multilingüe y `robots.txt`.
- **Diseño Adaptativo con Alto Contraste:** Selector de Tema Claro / Oscuro con detección automática del sistema operativo.

---

## 🛠️ Tecnologías y Stack

- **Framework:** React 19 + TypeScript
- **Bundler & Dev Server:** Vite 8
- **Estilos:** Tailwind CSS v4 + Vanilla CSS Moderno
- **Despliegue Multi-Hoster:** Compatible con Vercel (`vercel.json`) y Netlify (`netlify.toml` + `public/_redirects`)

---

## 🚀 Puesta en Marcha en Local

### 1. Instalación de Dependencias
```bash
cd front
npm install
```

### 2. Servidor de Desarrollo
```bash
npm run dev
```
Acceso en el navegador: `http://localhost:5173`

### 3. Compilación de Producción
```bash
npm run build
```

## 📂 Estructura del Proyecto

```
ARBOLEDA_MULTISERVICIOS/
├── front/                          # Código fuente de la aplicación web
│   ├── public/                     # Recursos estáticos, imágenes, vídeos, robots.txt, sitemap.xml
│   │   ├── projects/               # Fotografías de proyectos y catálogos
│   │   └── videos/proyectos/       # Vídeos MP4 de instalaciones reales
│   ├── src/
│   │   ├── components/             # Componentes modulares (Galería, Vídeos, Proceso, Cookies, etc.)
│   │   ├── config/                 # Configuración de empresa (companyData) y textos legales (legalTexts)
│   │   ├── pages/                  # Página principal de aterrizaje (LandingPage)
│   │   ├── translations.ts         # Diccionario centralizado de los 7 idiomas
│   │   └── index.css               # Estilos globales y tokens de diseño
│   ├── vercel.json                 # Enrutamiento SPA para Vercel
│   └── netlify.toml                # Enrutamiento SPA para Netlify
├── scripts/                        # Scripts de automatización en batch (.bat)
│   ├── start-front.bat             # Iniciar servidor local
│   ├── stop-front.bat              # Detener servidor
│   ├── build-front.bat             # Compilar para producción
│   └── preview-front.bat           # Vista previa del build
├── netlify.toml                    # Configuración raíz de Netlify
├── .gitignore                      # Exclusiones de control de versiones
└── README.md                       # Documentación técnica del proyecto
```
